Place your logo image here when using Docker Compose. Set `branding.logoFile` in
`deploy/compose.config.json` to `/app/branding/logo.png` (or your actual filename).
For a wide logo that already includes its name, set `branding.logoLayout` to `wide`.
PNG, JPEG, WebP, GIF, AVIF and SVG images up to 2 MB are supported.
